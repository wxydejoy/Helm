安卓端怎么用（App 名：岸亭）

  1. 安装 APK：从 GitHub Release 下载 APK（文件名可能仍是 Helm-*.apk），允许「安装未知应用」。
  2. 打开岸亭（横屏全屏）。未连 Hub 前是预览模式，数据是假的。
  3. 点主屏顶部 PC 监控条（CPU / 内存那一行）进入设置。
  4. 填入：
    「地址」→ …
    「端口」→ 17890
    「Token」→ 上面复制的 Token
  5. 点测试连接。成功会提示「已连接 study」并自动回到主屏。
  6. 回到主屏后应能看到真实温度、灯/开关和电脑监控；约每 3 秒刷新。
连不上？
  • 确认 Windows 上岸亭 Hub 正在运行（托盘有图标）
  • 手机和电脑是否同一局域网（不要一个 Wi‑Fi 一个有线不同网段）
  • Windows 防火墙放行 TCP 17890（Hub 日志里有命令）
  • Token 是否与上面完全一致（重新生成 Token 后安卓也要改）

⑤ 电脑监控

不装额外软件也能显示 CPU / 内存占用；有 NVIDIA 显卡还会显示 GPU。若要显示 CPU 温度，需要下面两项。

CPU 温度：PawnIO 是什么？怎么装？

PawnIO 是 Windows 上的一个小驱动，让普通程序能读到 CPU 温度传感器。 Hub 通过它把温度发给安卓；不装也不影响开关灯、启动程序等其他功能，只是主屏上没有 CPU 温度数字。

还需要：岸亭 Hub 必须以管理员身份运行（右键 exe → 以管理员身份运行，或用 run-admin.ps1）。

  1. 右键「终端 / PowerShell」→ 以管理员身份运行
  2. 执行安装命令（推荐）：
    winget install -e --id namazso.PawnIO
  3. 没有 winget 时：打开 GitHub Release 或 pawnio.eu 下载安装包，双击安装
  4. 装完后退出 Hub 托盘，再以管理员身份重新启动岸亭 Hub
  5. 安卓主屏 PC 监控条里应出现 CPU 温度；若没有，看日志 %USERPROFILE%\.config\dock-hub\hub.log

⑥ 安卓可选设置

都在岸亭的设置页（同样点顶部 PC 监控条进入）：

  • 视频背景：选本地横屏视频，循环静音播放
  • 方块样式 / 字体：调整主屏磁贴外观和时钟字号
  • 插电亮屏、拔电熄屏：需授予设备管理员（仅用于锁屏）
  • 媒体控制（右侧上一首 / 播放 / 下一首）：需在系统里开启岸亭的通知使用权
